Conventions

IDs are signed 64-bit integers on the native API and appear as JSON numbers. The compatibility layer converts them to strings.

Timestamps are Unix milliseconds. The compatibility layer returns ISO-8601 strings instead.

Bodies are JSON with Content-Type: application/json, except uploads, which are multipart form data on the dedicated upload routes.

Pagination for messages uses before, after, around and limit query parameters. Member pages use an offset or cursor as returned by the guild detail.

Errors use the HTTP status plus a JSON body with an error string. See Authentication → Errors for the full table.
